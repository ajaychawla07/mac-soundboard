# 🔊 Mac Soundboard (MyInstants Edition)

A fast, lightweight, and modern soundboard app for macOS with tactile instant buttons, global keyboard shortcuts, background running, sound uploading, 1-click sound pack sharing, and a built-in meme/SFX preset catalog.

---

## ✨ Key Features

### 1. 🔘 MyInstants-Style 3D Tactile Buttons & Colors
- Real tactile 3D push buttons with responsive spring animation, bevel lighting, and real-time audio equalizers.
- Palette of 12 vibrant MyInstants colors (Crimson, Neon Orange, Amber, Yellow, Emerald, Teal, Cyan, Electric Blue, Indigo, Violet, Hot Pink, and Slate).

### 2. ➕ Rich Upload Flow
- Click **"Upload Sound"** or drag & drop audio files directly into the window.
- Customize sound name, pick category, choose button color, and record a global shortcut.
- Instant in-modal audio preview before adding.
- Supports `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`, `.aac`.

### 3. 🌟 Discover Preset Library
- Switch to the **"Discover Presets"** tab to explore iconic sounds:
  - *Vine Boom*, *Metal Pipe*, *Ka-Ching*, *Emotional Damage*, *Dun Dun Dun*, *Sad Violin*, *Level Up*, *Record Scratch*, *Judge Gavel*, *Referee Whistle*, *Cartoon Boing*, *Classic Oof*, and more!
- Click any button to preview the audio instantly.
- Click **"+ Add to Soundboard"** to install it into your soundboard with one click.

### 4. 📦 Easy Sharing & Pack Export/Import
- **"Share Pack" (Export)**:
  - Bundles all your sounds, colors, names, and shortcuts into a single shareable `.soundboard` file.
  - Send this 1 file to a friend via AirDrop, Discord, or Google Drive!
- **"Import Pack"**:
  - Click "Import Pack" or drag & drop a `.soundboard` file into the app.
  - All sounds, audio files, and hotkeys are immediately installed and ready to play!

### 5. 📥 One-Click Audio Download
- Every sound card has a **Download (📥)** button to export the audio file directly to your Downloads folder or save anywhere on your Mac.

### 6. ⚡ Global Keyboard Shortcuts & Background Mode
- Triggers sounds from any game or app in the background.
- Runs quietly in the macOS menu bar.
- Panic button: **`Option + 0` (`⌥0`)** to silence all audio instantly.

---

## 🚀 How to Run (No Terminal Needed!)

### Option 1: Native Mac App (Recommended)
1. Open [`dist/mac-arm64/`](file:///Users/home/Desktop/soundboard/dist/mac-arm64/).
2. Drag **`Mac Soundboard.app`** into your **`/Applications`** folder.
3. Open it via Spotlight (`⌘ Space` -> type `Mac Soundboard`), Launchpad, or the Applications folder!

### Option 2: Double-Click Launcher
- Double-click [`Launch Soundboard.command`](file:///Users/home/Desktop/soundboard/Launch%20Soundboard.command) inside this folder.

### Option 3: Terminal (For Developers)
```bash
npm start
```
